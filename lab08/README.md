# Отчёт по лабораторной работе №8

## Пуассоновский поток. События на сервере

### 1. Цель работы

Смоделировать поток запросов на сервер как **простейший пуассоновский поток** и провести статистическую обработку результатов:

- определить число запросов за интервал времени **T** (выбран самостоятельно),
- построить **эмпирическое распределение** числа запросов за интервал **T**,
- вычислить **среднее** и **дисперсию**,
- сделать **вывод**.

### 2. Теоретическая часть

В простейшем потоке событий число событий на интервале времени **T** распределено по закону Пуассона:

$$
N(T) \sim \text{Poisson}(\mu),\quad \mu = \lambda T
$$

где **λ** — интенсивность (среднее число событий в единицу времени). Для распределения Пуассона справедливо:

$$
\mathbb{E}[N(T)] = \mu, \quad \mathbb{D}[N(T)] = \mu
$$

### 3. Алгоритм моделирования

Для каждого интервала времени **T**:

1. Генерируем последовательность межприходных времен, распределённых экспоненциально:

$$
   \Delta t = -\ln(U)/\lambda
$$

2. Суммируем $\Delta t$ до тех пор, пока сумма не превысит **T**.
3. Количество пришедших событий — это число запросов за интервал.

Повторяем эксперимент **N** раз, строим эмпирическое распределение, вычисляем среднее и дисперсию и сравниваем с теорией.

### 4. Реализация

- **Backend:** OCaml + Dream, эндпоинт `/api/simulate`.
- **Frontend:** HTML + TailwindCSS + JavaScript, визуализация графика (Chart.js) и таблицы распределения.
- **Docker:** backend и frontend запускаются через `docker compose`.

### 5. Запуск

```bash
docker compose up --build
```

Открыть в браузере: **http://localhost:3008**

### 6. Вывод

Эмпирическое распределение числа запросов за интервал времени **T** сходится к теоретическому распределению Пуассона. Среднее и дисперсия в эксперименте близки к $\mu = \lambda T$, что подтверждает корректность модели простейшего потока событий.
